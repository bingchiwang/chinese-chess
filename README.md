# 中國象棋 (Chinese Chess) - Java 人機對弈系統

一個使用純 Java (Swing + AWT) 開發的中國象棋遊戲，提供多種材質風格的棋盤介面、傳統書法楷體棋子（精確致中）、完整嚴格的象棋規則判定、每局 3 次悔棋限制，以及具備三種難易度的電腦 AI。

---

## 🌟 遊戲特點

1. **傳統書法楷體棋子（絕對致中）**：
   - 採用 Windows 傳統書法**標楷體 (DFKai-SB)** 與楷體字型，還原真實傳統木質印刻象棋質感。
   - 透過 Java 2D `GlyphVector.getVisualBounds()` 進行字形墨跡幾何輪廓計算，消除字型基準線（Baseline）偏差，達成 **100% 水平與垂直絕對精確致中**。

2. **自訂切換棋盤樣式**（頂部工具列即時切換）：
   - 🪵 **經典木紋**：溫暖黃褐色實木底板，搭配細緻年輪木紋與深木外框。
   - 🏛️ **典雅大理石**：冷灰石質底盤，搭配天然雲紋石理與青鋼石刻格線。
   - ⚪ **簡約純色**：無炫光柔和啞光米白底色，搭配墨黑線條，乾淨純粹護眼。
   - 🟢 **翡翠玉石**：青翠玉石漸層流光，搭配深翠邊框與金綠內飾。
   - 📜 **復古羊皮**：典雅懷舊羊皮紙質，搭配焦褐線條與皮革邊框。

3. **每局 3 次悔棋機制 (Undo Limit)**：
   - 嚴格落實**每局限 3 次悔棋機會**，介面按鈕與狀態面板即時動態顯示剩餘次數（例如 `悔棋 (3/3)`、`悔棋 (2/3)`）。
   - 3 次用盡後自動鎖定，防範過度悔棋，提升對弈嚴肅性與趣味性。
   - 當電腦正在深思時若點擊悔棋，能即時中斷 AI 計算並立即回朔玩家走步。
   - 悔棋時同步回朔右側「對局著法記錄（棋譜）」與吃子狀態。

4. **三種 AI 難易度選擇**：
   - 🟢 **簡單 (初學者)**：深度 1~2 搜索，反應迅捷（約 50ms），帶有隨機性擾動，偶有走子疏漏，非常適合象棋新手入門及學習。
   - 🟡 **中等 (業餘進階)**：深度 3 Alpha-Beta 剪枝搜索 + 棋子位置價值表 (PST)，兼顧戰術進攻與防守。
   - 🔴 **困難 (棋力大師)**：深度 4 搜索 + 靜態搜索 (Quiescence Search) 避免地平線效應，並採用 MVV-LVA 走法排序，算力強大，具備高級攻殺與殘局能力。

5. **完整嚴謹的象棋規則實作**：
   - **九宮與走法限制**：帥/將、仕/士嚴格限制在九宮內活動。
   - **飛將照面判定 (對面笑)**：兩方將帥同列無子阻擋視為違例，走子後不得造成照面。
   - **塞象眼與不能過河**：相/象走田字，田字中央有子即塞象眼；相/象終身不可越過楚河漢界。
   - **蹩馬腿**：馬走日字，前進拐彎方向若緊鄰有子則受阻。
   - **炮隔子打**：平移無阻擋，吃子必須恰好翻過一個任意棋子（炮架）。
   - **兵/卒過河規則**：過河前只可向前，過河後可向前及左右橫走，絕不可後退。
   - **將軍與困斃判定**：即時檢測被將軍狀態；無合法走子時依象棋規則判定為負（將死或困斃）。

6. **豐富的輔助功能**：
   - **執子選擇**：玩家可自由選擇「玩家執紅 (先手)」或「玩家執黑 (後手，棋盤自動翻轉為黑方視角)」。
   - **AI 走法提示 (Hint)**：可請電腦分析並以綠色箭頭標示最佳推薦走法。
   - **對局著法記錄 (棋譜)**：右側欄以標準中文記譜法（如「炮二平五」、「傌八進七」）即時記錄每一步棋。
   - **吃子展示區**：即時展示雙方當前所吃得之棋子。
   - **認輸與重開局**：隨時投降認輸或重新設定條件開局。

## 🚀 啟動方式

### 方法 1：直接雙擊執行 (Windows)
在遊戲資料夾中直接雙擊：
```
啟動遊戲.bat
```
或 `run.bat`

### 方法 2：使用 JAR 執行
```bash
java -jar ChineseChess.jar
```

### 方法 3：從原始碼編譯執行
```powershell
# 編譯
javac -encoding UTF-8 -d bin src/xiangqi/*.java

# 執行
java -cp bin xiangqi.Main
```

### 執行單元自測程式 (驗證 10 項規則、AI 與悔棋上限)
```powershell
java -cp bin xiangqi.XiangqiTest
```

## 📁 專案架構

```
象棋/
├── ChineseChess.jar             # 完整可執行的 Java 歸檔檔案
├── 啟動遊戲.bat                  # Windows 一鍵啟動腳本
├── run.bat                      # ASCII 雙擊啟動腳本
├── README.md                    # 本專案詳細說明文件
├── GEMINI.md                    # 專案開發規範（修改檔案自動同步 GitHub）
├── bin/                         # 編譯輸出之 Class 檔案
└── src/
    └── xiangqi/
        ├── Main.java            # 應用程式啟動入口
        ├── MainFrame.java       # 主視窗 GUI 介面（工具列、資訊卡、棋譜表格）
        ├── ChessBoardPanel.java # 棋盤繪製、材質紋理、棋子書法字幾何致中與滑鼠互動
        ├── BoardTheme.java      # 棋盤材質樣式列舉（經典木紋、大理石、簡約純色、翡翠、羊皮）
        ├── GameController.java  # 遊戲流程控制、3 次悔棋限制與人機對弈
        ├── Board.java           # 棋盤核心狀態、所有棋子規則與走法生成
        ├── Piece.java           # 棋子類別
        ├── PieceType.java       # 兵種類型列舉 (GENERAL, HORSE, CANNON, etc.)
        ├── PieceColor.java      # 紅黑陣營列舉
        ├── Move.java            # 走步資料結構
        ├── Evaluation.java      # 棋力估值系統 (子力價值 + PST 位置權重表)
        ├── AIPlayer.java        # 電腦 AI 引擎 (Minimax + Alpha-Beta + Quiescence)
        ├── Notation.java        # 中文傳統記譜法轉換工具
        └── XiangqiTest.java     # 核心規則、AI 與 3 次悔棋限制自動化單元測試
```
