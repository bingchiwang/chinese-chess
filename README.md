# 中國象棋 (Chinese Chess) - Java 人機對弈系統

一個使用純 Java (Swing + AWT) 開發的中國象棋遊戲，提供精美的木質棋盤介面、繁體書法棋子、完整嚴格的象棋規則判定，以及具備三種難易度的電腦 AI。

---

## 🌟 遊戲特點

1. **三種 AI 難易度選擇**：
   - 🟢 **簡單 (初學者)**：深度 1~2 搜索，反應迅捷（約 50ms），帶有隨機性擾動，偶有走子疏漏，非常適合象棋新手入門及學習。
   - 🟡 **中等 (業餘進階)**：深度 3 Alpha-Beta 剪枝搜索 + 棋子位置價值表 (PST)，兼顧戰術進攻與防守。
   - 🔴 **困難 (棋力大師)**：深度 4 搜索 + 靜態搜索 (Quiescence Search) 避免地平線效應，並採用 MVV-LVA (最有價值受害者-最少價值攻擊者) 走法排序，算力強大，具備高級攻殺與殘局能力。

2. **完整嚴謹的象棋規則實作**：
   - **九宮與走法限制**：帥/將、仕/士嚴格限制在九宮內活動。
   - **飛將照面判定 (對面笑)**：兩方將帥同列無子阻擋視為違例，走子後不得造成照面。
   - **塞象眼與不能過河**：相/象走田字，田字中央有子即塞象眼；相/象終身不可越過楚河漢界。
   - **蹩馬腿**：馬走日字，前進拐彎方向若緊鄰有子則受阻。
   - **炮隔子打**：平移無阻擋，吃子必須恰好翻過一個任意棋子（炮架）。
   - **兵/卒過河規則**：過河前只可向前，過河後可向前及左右橫走，絕不可後退。
   - **將軍與困斃判定**：即時檢測被將軍狀態；無合法走子時依象棋規則判定為負（將死或困斃）。

3. **典雅擬真的視覺效果與互動**：
   - 仿實木紋漸層底盤、標準楚河漢界書法字樣、九宮斜線、兵位炮位十字折角標記。
   - 立體圓形木質棋子，搭配標楷體 (DFKai-SB) / 微軟雅黑書法字形。
   - 選中棋子金色外圈、合法著點（綠色圓點/紅色吃子括圈）。
   - 上一步走子起點與終點標示（藍色/金色框）。
   - 被「將軍」時的帥/將紅色警示光圈與提示音。

4. **豐富的輔助功能**：
   - **執子選擇**：玩家可自由選擇「玩家執紅 (先手)」或「玩家執黑 (後手，棋盤自動翻轉為黑方視角)」。
   - **悔棋 (Undo)**：支援隨時悔棋，自動撤銷電腦與玩家的前一步。
   - **AI 走法提示 (Hint)**：可請電腦分析並以綠色箭頭標示最佳推薦走法。
   - **對局著法記錄 (棋譜)**：右側欄以標準中文記譜法（如「炮二平五」、「傌八進七」）即時記錄每一步棋。
   - **吃子展示區**：即時展示雙方當前所吃得之棋子。
   - **認輸與重開局**：隨時投降認輸或重新設定條件開局。

## 🚀 啟動方式

### 方法 1：直接雙擊執行 (Windows)
在遊戲資料夾中直接雙擊：
```
啟動遊戲.bat
```

### 方法 2：使用 JAR 執行
```bash
java -jar ChineseChess.jar
```

### 方法 3：從原始碼編譯執行
```powershell
# 編譯
javac -encoding UTF-8 -d bin src/xiangqi/*.java

# 執行
java -cp bin xiangqi.Main
```

### 執行單元自測程式 (驗證規則與 AI)
```powershell
java -cp bin xiangqi.XiangqiTest
```

## 📁 專案架構

```
象棋/
├── ChineseChess.jar             # 完整可執行的 Java 歸檔檔案
├── 啟動遊戲.bat                  # Windows 一鍵啟動腳本
├── README.md                    # 本專案詳細說明文件
├── bin/                         # 編譯輸出之 Class 檔案
└── src/
    └── xiangqi/
        ├── Main.java            # 應用程式啟動入口
        ├── MainFrame.java       # 主視窗 GUI 介面（工具列、資訊卡、棋譜表格）
        ├── ChessBoardPanel.java # 棋盤與棋子繪製、滑鼠互動
        ├── GameController.java  # 遊戲流程控制、人機回合計時與狀態維護
        ├── Board.java           # 棋盤核心狀態、所有棋子規則與走法生成
        ├── Piece.java           # 棋子類別
        ├── PieceType.java       # 兵種類型列舉 (GENERAL, HORSE, CANNON, etc.)
        ├── PieceColor.java      # 紅黑陣營列舉
        ├── Move.java            # 走步資料結構
        ├── Evaluation.java      # 棋力估值系統 (子力價值 + PST 位置權重表)
        ├── AIPlayer.java        # 電腦 AI 引擎 (Minimax + Alpha-Beta + Quiescence)
        ├── Notation.java        # 中文傳統記譜法轉換工具
        └── XiangqiTest.java     # 核心規則與 AI 自動化單元測試
```
